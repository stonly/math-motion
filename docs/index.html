Privacy Policy

KaTeX Sidebar Chrome Extension — Last updated March 2026

KaTeX Sidebar does not collect, store, or transmit any personal data.

Data Storage

All user preferences (insertion mode, toolbar preset, font settings, and symbol history) are stored locally on your device using Chrome's storage API (chrome.storage.local). This data never leaves your browser.

Permissions

  • sidePanel — Display the symbol picker sidebar.
  • scripting — Inject content scripts for symbol insertion on non-Notion pages.
  • activeTab — Access the current tab for inserting symbols.
  • storage — Persist user preferences locally.
  • clipboardRead — Read clipboard for "Paste LaTeX" and "Paste Image" features.
  • clipboardWrite — Copy equations to clipboard via "Copy LaTeX".

Host Permissions

The extension requests access to notion.so and notion.site domains only. This is required to detect Notion math blocks and enable auto-open of the sidebar.

Third-Party Services

This extension does not communicate with any external servers or third-party services.
